## Implemented reader improvement

Added **Check now** beside the inbox, plus the timestamp of the last successful receiving API check. It shares the existing poller and current inbox; it cannot create an address or extend expiry. It disables while disconnected, expired or checking. Successful empty checks give explicit feedback; failed checks preserve the prior successful timestamp and surface the existing connection error. Background polling remains automatic. No message, SMTP or compatibility guarantee is added.

The change affects the homepage and existing routes embedding the inbox. Only those routes' substantive dates advance; guide-only Steam and Venmo retain their actual dates. No backend, schema, credentials or paid service change is needed. A local preview on 127.0.0.1 correctly remained disconnected because that origin is absent from the project's existing CORS list; functional testing uses its configured localhost origin without broadening access.

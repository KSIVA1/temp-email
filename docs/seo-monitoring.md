# InboxForNow daily SEO monitoring

Current scope, updated October 13, 2026: https://inboxfornow.com, Astro static frontend on Cloudflare Pages, Google US English desktop, America/Chicago. The machine-readable watchlist is [seo-targets.json](seo-targets.json): 14 priority searches across ten categories. The expanded workflow supersedes the historical three-query/two-day protocol. First-page confirmation now requires all priority queries on actual page 1 at organic rank at most 10 for seven consecutive compatible calendar days, followed by manual review of the original evidence. First-place progress is separate.

The existing automation is **inboxfornow-daily-seo**, daily at **9:00 AM America/Chicago**. The user explicitly requested a report every day, including unchanged days, containing the clickable absolute dashboard link, completed changes/publication and blockers. Do not create a duplicate automation or revert to quiet-only reporting.

## Daily sequence

1. Read config, the [expanded audit/plan](research/2026-10-13-expanded-seo-plan.md), latest worklog and prior dated artifacts.
2. Run `npm run seo:monitor`. Compare crawl, robots, declared local assets/downloads, genuine 404, API and receiving-domain MX checks with prior snapshots. The script saves timestamped originals under `.seo-cache/daily/YYYY-MM-DD/` and uses America/Chicago dates.
3. Collect authorized Search Console US desktop Web query/page metrics for fully processed comparable 7-day/previous-7-day and 28-day/previous-28-day windows. Preserve originals privately, exact dates, last update and processing caveats. Record unavailable measurements instead of using old caches.
4. Inspect actual Google pages 1–4 for every target, following visible pagination until the intended canonical page is found. Preserve originals and organic-order explanations as below. Stop further ranking queries for the run on an unusual-traffic/verification challenge; save the challenge and mark remaining queries unknown. Do not switch profiles, accounts, proxies or providers to evade it.
5. Preserve any same-day original before replacing `rankings.json` with deeper or newer observations. Normalize all targets, including unknowns. Run `npm run seo:rankings`; investigate validation errors, never suppress them.
6. Choose a high-priority evidence-backed product/content/discovery item. Implement and publish justified work when available, or document why an experiment should wait and investigate an independent item. No cosmetic daily changes or generic page expansion.
7. Run `npm run seo:dashboard`. Verify dates, query coverage, evidence integrity and gap labels; refresh/reopen the saved HTML. Report the absolute clickable dashboard link every day. Record work and the next action in `docs/seo-worklog.md`.

## Actual Google evidence contract

Start each query at `https://www.google.com/search?q=ENCODED_QUERY&gl=us&hl=en&pws=0`, signed out, on desktop. Verify the visible IP-derived US locality on each accepted page. Today's locality was Phillips Creek Ranch, Frisco, TX. One locality is not universal nationwide visibility.

Inspect standard linked organic web results in visual order. Exclude ads, AI citations, carousels, related-search modules and secondary sitelinks. Standalone linked web results from video sites can count; do not count a video carousel as individual web results. An automatic heading selector only supplies candidates: manually verify modules/order against the preserved DOM/screenshot before accepting a page. Preserve opaque Google outbound URLs exactly; never guess competitor destinations. If InboxForNow appears, verify the actual destination/canonical rather than counting an opaque redirect as a site match. Wrong-site or different intended-page results do not satisfy that query's target.

For each accepted page save its number, timestamp, actual search URL, next visible pagination URL, ordered `results` (`title`, `url`), locality, organic-order explanation, original DOM path/SHA-256 and screenshot path/SHA-256. Follow visible Next/page links; a missing Next button or early stop does not establish absence through page 4. Unexpected unrelated results or unverifiable locality/order remain gaps, with originals retained.

The combined source is `.seo-cache/daily/YYYY-MM-DD/google-us-serp.json`: engine, country `US`, language `en`, device `desktop`, site, and an `observations` array. Each observation matches its normalized query, timestamp, status, search URL, exact rank, ranked URL, checked depth/count and actual page/within-page position; it includes `pages` and their combined ordered `results`.

The normalized `rankings.json` has `version: 1`, `day`, engine/country/language/device/site, `targetFingerprint` from `targetFingerprint(config)` in `scripts/lib/seo-rankings.mjs`, and every target exactly once in `observations`. Each record includes:

- `query`, intended `path`, actual `observedAt` and `searchUrl`.
- `status`: `observed`, `absent_first_page` (legacy enum name for absence at any accepted depth), or `unknown`.
- `checkedThroughPage` (0–4), actual `checkedThroughRank`, `exactOrganicRank`, `rankedUrl`, `resultPage`, `rankWithinPage`, `source: google_us_serp`, `organicWebResultsVerified` and a gap `reason` where relevant.
- For accepted pages, `evidence: {path, sha256}` pointing to the combined source; all original page artifacts must still hash correctly.

An observed placement needs positive integer exact rank, actual result page and within-page position, the intended canonical URL, and verified preceding-page counts. Overall rank is preceding organic result count plus within-page position. **Never infer page by dividing rank by ten.** Absence and unknown have null exact rank/ranked URL/page position. Unknown with zero accepted pages requires a reason and must not claim a page visit. An inspected challenge is saved separately; unvisited remaining queries share that run-level blocker without fabricated individual observations.

Only absence with four accepted actual pages displays **Not found through page 4**. Shallower absence displays **Depth incomplete**. Today's disposable-email row retains its original morning timestamp and first-page evidence; the later challenge is not substituted for a new ranking. New targets have no fabricated earlier history. Original October 9–12 snapshots are read through an explicit historical first-page-only bridge, retain their scope and can never establish completion of the expanded target set.
